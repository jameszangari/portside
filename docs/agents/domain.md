# Domain references

Portside is a single native macOS application. Read `CONTRIBUTING.md` and `AGENTS.md` first. Use `docs/ARCHITECTURE.md` for components and API boundaries, `docs/DATA.md` for persisted settings, and `docs/PLAN.md` for design intent. Current work and known gaps live in `docs/CHECKLIST.md`.

There is no separate CONTEXT.md. Read relevant decisions in `docs/adr/` if that directory is introduced. Do not invent an ADR history or duplicate the existing domain docs.
