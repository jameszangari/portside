# Triage labels

- `needs-triage`: needs initial review.
- `needs-info`: waiting for reporter information.
- `ready-for-agent`: specified sufficiently for implementation by an agent.
- `ready-for-human`: requires human work or judgment.
- `wontfix`: will not be implemented.

Check which labels exist before applying them. These are conventions, not a claim that the remote labels have been created.
